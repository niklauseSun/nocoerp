# 商家微信小程序开发预览

- 原生小程序在 `miniapp/`，独立于后台 React 客户端，不创建 NocoBase 插件。原生 WXML/WXSS/CommonJS；共享语义颜色在 `miniapp/app.wxss`，文案在 `miniapp/lib/copy.js`。不得强行使用 React/shadcn。
- 当前仅本地开发预览，不是真实后端接入。手机号/商户/账单为明确演示数据，数据隔离存于本地 namespace；不得开启真实身份验证或资金操作的假成功通道。见 [说明](../../miniapp/README.md)。
- 用户确定正式需求：微信小程序；授权手机号匹配、多商户；每日营业额/订单数及附件；账单缴费/缴费记录；报修；物业统一收款。目前无 AppID、微信支付商户号和HTTPS域名。缺少凭证不意味着服务端开发已经完成；真实集成仍待实现。
- 生产阶段须复用 Better Auth、已有授权及营收/账单/收银/报修唯一账本；真实手机号由微信接口验证，AppID+OpenID绑定身份。授权手机号管理独立于普通联系人号码；每次访问重新校验，撤权不能只隐藏菜单。
- 预览切换商户/页签/退出确认未保存内容；图片异步保存期间禁止切换，卸载后返回的文件须清理。草稿提交失败保留表单；模拟支付精确分、请求幂等，不调用 requestPayment、不写正式财务数据。
- `tests/miniapp` 的模型、页面控制器和WXML静态检查不等价于原生编译/真机验收。真实平台、主题、图片API和支付尚未验证时必须明确报告。
