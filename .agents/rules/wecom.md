# 企业微信自建应用

- 单企业自建应用集成，server/wecom/、server/providers/wecom.ts、server/routes/wecom.ts；客户端 /wecom 及新建弹窗、对比子页。配置在 server/config/wecom.ts，默认关闭；Secret 只在服务端。接入步骤见 [接入文档](../../docs/企业微信自建应用接入.md)。
- 复用 Users 公共接口、Organization 与官方 Notification provider/channel 扩展；不创建插件、不直写插件表。接口同时校验企业微信设置、组织和用户权限。新用户随机密码且无角色；停用检查保护角色。
- 映射由管理员明确创建，以 corpId/kind/localId 或 remoteId 唯一；不按姓名或邮箱猜测关联。首次手动同步，后续可启用每五分钟最多20条已建立基线的双向比较；不自动发现新成员、不传播删除、不复制角色或项目授权。
- 姓名/邮箱/部门归属/主部门/启用状态及部门名称/父级同步；邮箱与完整可见范围必需。权限缩小不能当作完整快照；接入者须保证完整通讯录可见范围。缺少字段或映射依赖拒绝。无手机号或单点登录。
- 基线三方比较，双边修改冲突需人工选择。提交指纹+版本CAS，持久化 intent/intentDirection，外部写在事务外；本地拉取与映射完成同事务。未知结果禁止重发，仅只读核实；执行中至少120秒后核实。局部预校验失败不得误标外部结果未知。
- 通知沿用个人订阅和实时业务授权，冻结 corp/agent/单用户收件人/内容，独立于站内投递。相同待办代次稳定幂等键；明确失败重试原 Delivery，结果未知禁止新发。禁止 @all，配置企业/应用不符拒绝旧消息。
