# Mobile workbench and responsive field work

`/workbench` is signed-in/personal (`authz: skip`) and the phone landing from `/`; desktop `/` retains the dashboard. Public personal entries use session ownership; protected feature tiles require BOTH original page access and business read. Workbench approval detail child explicitly retains `page:hyl-approvals/access`. Never grant roles merely to make mobile links appear. Workbench uses existing APIs and actor/revision query cache, at most5attention items with server totals; no duplicate backend/mobile database.

`client/components/responsive-table.tsx` has an explicit direct Table/Body/Row composition contract. On phones it renders actual existing cell children into Cards with translated labels supplied by the domain, reusing action/checkbox eligibility without duplication. Desktop renders the original table. Energy selection makes titleIndex1, never make a checkbox the record heading. Sorting remains server-side with same URL; preserve all selected-ID/generation/50-cap logic in parent page. Do not pass an opaque component or fragments instead of concrete TableBody/Rows.

Shell bottom navigation owns a separate flex row below main; it never overlays RouteChildPage/form footers. Original filtered sidebar still owns all-features navigation. Header drops duplicate phone brand to leave room for trail/account; full brand remains in the menu. CSS phone overrides are in client/styles.css, semantic tokens, 44px targets and16px inputs intentional. Don't edit generated primitives. Hook useIsMobile initializes matchMedia synchronously to prevent unauthorized desktop/dashboard fetch flashes; subscribe to mql.matches, not parent-window widths (also works inside test iframes).

Workbench source previews open /workbench/todos/:messageTodoId and /workbench/approvalRequests/:approvalRequestId over the workbench. Source detail modules detect this bounded origin, preserve query in Back and keep original API permission checks. No arbitrary return URL or new source grants.

See [phone workflow](../../docs/手机工作台与现场作业.md). Tests in tests/mobile plus affected original business UI, shell and server workflows. Narrow iframe is valid viewport evidence, not physical-device/OS-keyboard/camera evidence. Temporary public/mobile-viewport-check.html is test-only and must not ship; keep only ignored screenshots. No sessions exported or saved.
