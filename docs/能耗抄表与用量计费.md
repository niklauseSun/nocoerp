# 能耗抄表与用量计费

能耗菜单包含水电表、抄表记录、用量出账。资产固定在表计上，合同通过起止日期绑定；公区表可独立抄表。表号全局唯一，倍率和初始校准创建后固定。

操作顺序：新建水电表 → 预览并绑定合同 → 保存抄表草稿 → 补齐读数和凭证后提交 → 财务审核 → 选择已审核来源并预览 → 生成账单草稿 → 在计费模块发布 → 统一收银部分收款与补收。

用量 =（本次读数 − 上次读数）× 倍率；金额 = 用量 × 对应费率。实际用量按真实读数计，不再次按不足月天数折算。每段日期连续且不能重叠；跨费率边界需要分段。零用量也必须保留原因、凭证和发布覆盖。

账单草稿会占用抄表来源，发布后标为已出账，作废后释放但保留链接历史。退款和冲销只改变原资金账，不自动允许重复出账。托管来源行不能直接删改，需要先作废原草稿。

换表时先完成旧表末读审核并交接结束绑定，新表从次日用自己的初始读数承接同一资产和合同。旧表费用出账发布后才能停用。接管旧配置表计需核对最后已发布读数边界，不能重写已发布记录。

合同详情的“检查退租末读与出账”按所选截止日检查：末次审核读数、发布期间覆盖、未收账单与未核销收款；归档事务再检查一次。缺少最后读数时不能靠无账单或零余额绕过。
