# 手机浏览器租户流程适配

2026-10-20，按用户指定的手机浏览器范围实现，中文默认，保留英文资源；不接微信小程序。设计经过一次独立审查，沿用用户明确授权的“后续无需再确认”。本轮未改变数据库、服务端计费或正式岗位授权。

## 使用入口和流程

本机开发入口：`http://127.0.0.1:13000/main/workbench`。这是电脑本机地址；手机真机访问需要使用部署地址或同网可达的开发主机地址，不能把手机上的127.0.0.1当作电脑地址。

| 流程       | 手机端变化                                                                                                                              | 业务边界                                                                                   |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 租户工作台 | 增加营业报送、结算确认、租户服务入口，保留原消息/待办与现场工作；入口同时检查页面及数据读取权限，pending隐藏                            | 结算入口默认筛选待商户确认；不新增岗位权限或虚构待办总数                                   |
| 营业报送   | 768px以下用卡片，保留筛选、服务端排序、分页和详情链接；编辑表单按报送信息、营业金额、凭证说明分组，单列、数字小数键盘与流内sticky保存区 | 先保存，再在原详情上传私密凭证及提交审核；失败保留中文输入和草稿；不把未报当零             |

| 租户服务   | 卡片列表、手机排序与筛选；长正文/历史换行、单列详情；导航自身横滚，不撑开页面                                                           | 公告签收、投诉建议提交、处理及反馈复用原状态/权限/版本/requestId，已完成操作仍显示禁用说明 |

## 通用适配

- 同一记录/单元格子树用于手机卡片及桌面表格，不另建手机财务算法或裁剪字段；768px及以上仍使用原表格。
- 共享弹窗根据visualViewport高度和offsetTop更新手机定位与限高，头脚固定、正文滚动；保留window fallback与卸载监听清理。16px输入、44px触控区域和safe-area复用现有规范，桌面定位不变。
- 报送及确认操作提交期间禁用按钮/关闭，客户端导航受guard保护；确认版本固定为最新读取完成时的基准，409需显式重新加载，保留异议文本。
- 详情刷新403/404不再显示缓存记录的旧操作；缺失记录刷新对应列表。覆盖页关闭复用来源/可见标题焦点恢复。
- 修复既有租户经营报表`hyl.options`错误翻译键，改用存在的enums，未知来源文本先检查键是否存在。
