# 自动分账流程

本模块只登记线下台账和模拟执行凭证，不调用支付渠道。

## 使用

1. 在“自动分账 → 合同规则”选择合同，设置生效日期、参与分账的费用类型、项目和合作方比例。比例合计100%，项目方恰好一个；保存前先预览。规则只增加版本，来源账期起始日决定版本，已有来源锁定快照。
2. 账单收款核销后自动生成账单分账；只有有效现金核销进入基数，押金抵扣和未核销余额不参与。未选中的费用归集，不返给商户。
3. 经营结算经复核、商户确认后自动生成经营分账。商户应返沿用原结算；管理费和结算内租金按规则分配，代垫费用单独归集。租金已走账单时，不再重复扣租。
4. 复核分账来源，再登记部分或全部执行。失败仅记尝试，不增加资金流水。流水号不得重复；未知结果保持原请求重试，修改后生成新请求。
5. 来源退款产生新调整版本并要求重新复核。超额已分形成“待追回”，可分次追回。误登记可冲销后重记；已关联追回的付款需先处理更正依赖。
6. 日结按上海时区的实际登记日汇总合作方分出、追回和冲销。商户返款继续走原结算统计。待复核、待分出、待追回未清，合同不能结清；已结清合同不能再登记执行。

权限分为查看、配置、复核、执行、追回，并与合同和来源的原有权限及记录范围共同生效。没有自动扩大现有岗位权限。
