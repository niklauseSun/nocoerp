# 租赁履约与押金流程

合同增加标题与应收押金，保留原计费规则及签约资产快照。新合同选择铺位或摊位：同商户已有完整覆盖租期的绑定直接复用，否则在同一事务内按租期建立绑定；任何占用冲突均整体回滚。

押金台账与经营收支分开。可用押金 = 收取 + 续租转入 − 抵扣 − 退款 − 续租转出。应收押金只是目标，不代表实际收款。所有操作仅登记线下台账，不触发支付。

续租建立新合同，默认原合同次日起租，允许空档；可不结转、部分或全部结转。转出、转入与新合同、资产绑定同一事务提交。原合同保留历史计费。结转不能超过可用余额或新合同押金目标。结转冲正成对处理；如新合同已消耗该款，需先冲正消费；已归档合同先重开财务结清。

退租输入实际退租日、原因、交接记录，先预览阻塞事项。退租日包含当天；结算使用自然周期与合同有效期的交集，首尾期按自然月实际天数折算。后续来源、有效结算或未来续租存在冲突时拒绝退租；已付款历史不改写。绑定至退租日关闭，次日可以新租，不提前释放未来交接的资产。

经营结算为负时，商户确认后仍保留原始 `due` 状态及金额快照，另派生待补缴、部分补缴、已补缴。剩余应补缴 = 原欠款 − 有效押金抵扣 − 有效补缴收款。补缴与经营返款分开登记，冲正会恢复欠款。

独立退租赔偿或交接扣款须填写唯一参考号、日期、原因、凭证，先建草稿再明确确认，才能抵扣或补缴。不允许将经营费用 ID 作为独立扣款来源；已经进入经营结算的费用应对该结算抵扣，不能另建独立费用重复收取。已应用的扣款须先冲正应用才能取消。

全部有效租期完整结算、报送和费用已审核并认领、经营返款及补缴结清、独立扣款无欠款、押金归零且已到退租日后，可结清归档。归档锁定业务来源和财务变更；说明原因后可重开财务结清，资产占用不会因此恢复。

流水不可直接编辑或删除。收取、退款、补缴、独立扣款参考号在合同内唯一；请求编号支持幂等重试，参数不同的重复请求拒绝。金额按整数分计算，合同版本及商户锁防止并发超收和超扣。新动作独立授权，按合同商户范围检查，不自动修改既有真实用户的权限配置。
