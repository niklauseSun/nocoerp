# 收费与统一收银流程

入口：左侧「收费与统一收银」，包含「收银单」「退款流水」「日结核对」。本模块登记线下收付款和凭证，不发起真实银行转账。

## 操作流程

1. 新建收银单，选择同一商户的已发布账单，可跨多个合同。输入各账单本次核销金额和押金抵扣金额。
2. 输入银行转账、现金或其他支付分笔，每笔填写金额、外部参考号、凭证和分合同金额。每笔分合同合计必须等于实收金额；同一合同实收可大于核销额，多收部分保留为该合同未核销余额。
3. 预览后保存草稿或登记。草稿不影响账单、押金或资金；登记在一个事务内完成所有收款和核销，明细关联原账单与收款流水。
4. 欠款可再建收银单补收。未核销余额可退款；退回已核销款时，明确选择核销来源和需恢复的金额，预览会显示恢复应收。
5. 错误退款可凭原因和凭证冲销。冲销恢复可核销余额，不自动重新核销账单，也不代表撤回真实转账。之后可重新登记退款或到原收款进行核销。
6. 所有账单剩余应收、押金余额、未核销余额和其他履约义务处理完毕后，在原合同页面执行退租结清。
7. 日结选择登记日和本人/授权范围，核对渠道汇总及来源流水，填写实盘现金和凭证；非零差额必须说明原因。确认后保留不可变快照，后续补录需创建新版本。

记录冲突会提示重新加载并预览；结果未知的请求保持同一个请求编号重试，避免重复收款。已登记快照不可编辑；作废、退款或冲销都保留来源和凭证。部分来源合同无权查看时整单不可见。
