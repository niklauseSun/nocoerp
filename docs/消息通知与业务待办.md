# 消息通知与业务待办

侧栏“消息通知”打开站内收件箱；“业务待办”查看本人当前有权处理的事项；“提醒设置”开启个人订阅，调整合同提前天数（1–90）、账单提前天数（0–30）和消息语言。

勾选项和阈值统一保存。默认关闭提醒，开启后系统每五分钟检查，或点击“检查提醒”立即更新。后台按最久未检查排序，每次至多检查十人，多用户时可能需要多轮。租约中的并发检查会提示稍后刷新，不重复发送。

| 类别       | 提醒条件                                           | 处理入口         |
| ---------- | -------------------------------------------------- | ---------------- |
| 租赁合同   | 生效租约未续租，临近或超过有效结束日               | 续租或退租       |
| 计费账单   | 已发布、剩余应收大于零，临近到期或已逾期           | 收款核销         |
| 工单报修   | 当前用户有权派单、处理、验收或关闭                 | 原工单对应操作   |
| 供应商采购 | 申请审批、转订单、订单发出、收货、验收或已验收未付 | 原采购单对应操作 |

“待处理”只表示业务条件仍满足；“已退出待办”表示条件不再满足或订阅已关闭。已读/未读由站内收件箱独立保存，标记已读不会办理业务。完成业务后再次检查，原待办退出，历史消息保留。需要接着处理的新阶段会形成新的待办。

同一用户、来源、原因和日期只生成一个提醒；重复检查不重复发送。已退出的相同条件再次出现时，增加提醒轮次。消息文案只含类别与处理提示；业务名称、金额等在点击后重新校验权限加载。撤权后无法再打开来源，不会继续发送新提醒。消息仅向本人发送，不批量通知其他账号。

投递“已投递”表示进入站内收件箱，不表示已读或业务完成。失败时在仍有效的待办详情重试原投递；未知结果不能新建逻辑消息。系统恢复时复用冻结文案和幂等键，避免接受成功但应用未记下回执时重复发消息。关闭订阅立即移出对应待办，历史消息不删除、不自动标已读。
