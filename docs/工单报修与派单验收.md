# 工单报修与派单验收

工单入口为“工单报修”。支持登记、派单、转派、开始处理、记录进展、提交验收、验收退回、验收通过和关闭。未完工工单可说明原因后撤销；已关闭、已取消的工单不能继续修改。

正常流程：待派单 → 已派单 → 处理中 → 待验收 → 已验收 → 已关闭。验收不通过退回处理中，整改后重新提交。处理人需为有效内部用户；开始、记录进展及提交验收还检查当前登录人是否是该工单处理人。派单、处理、验收和关闭有独立权限，演示使用现有管理员模拟这些岗位。

创建时必须选择资产。公区报修可不关联合同或商户；关联商户时校验报修日的资产绑定，关联合同时校验资产签约关联和有效租期，并以合同确定商户。资产、商户、合同和报修日创建后固定；错误关联通过撤销后重新登记纠正。各档案详情提供工单摘要和完整列表，工单内的关联档案在当前页面下只读打开，返回保留来源。

问题描述、现场依据、进展、完工依据和验收意见会保留。依据目前为文字或外部凭据说明。维修成本是本次维修的最新总成本登记值；整改后重报总成本，旧值保存在提交验收历史中，不将两次总额相加。该登记不会自动生成收费账单或真实支付。

接口按工单动作权限与资产、商户、合同读取范围的交集授权。隐藏的关联合同或商户会使该工单不可见，列表数量也按授权结果计算。管理员可在既有权限编辑器配置 `hyl-repairs` 页面和 `hyl.repairs` 的查看、报修、派单、处理、验收、关闭、撤销权限；模块不会自动给普通用户扩权。

操作包含版本检查和请求防重，同一请求重试不会重复登记；冲突需重新加载最新记录。表单未保存时离开会确认，未知响应可以保留原请求重试。列表每页20条、选择器每页20条，处理历史按记录版本排序并分页。
