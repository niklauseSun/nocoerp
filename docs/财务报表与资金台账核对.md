# 财务报表与资金台账核对

入口 `/financialReports`。报表直接读取原始业务台账，金额使用整数分和 BigInt，不生成第二套资金流水。

## 统计口径

- 收支按上海时区登记日期筛选，凭证日期另列；冲销在自身登记日反向入账。期初、期末为累计登记净额，不是银行余额或利润。
- 应收应付和当前押金是生成报表时的事务快照，不随日期筛选变成历史余额。
- 应收包括已发布账单、已确认退租费用及负结算补缴，减有效核销、补收和押金抵扣。草稿、未确认业务不计入。
- 应付包括已确认商户结算减原始返款，以及采购验收计提减付款、加付款冲销；不把采购订单总额提前计入应付。
- 押金期初＋期间净变动＝期末。当前余额另列；未核销收款作为预收单列。抵扣、续租结转、核销和开票不形成现金。
- 搜索、排序、分页只改变明细，不改变汇总；汇总穷尽全部授权来源。
- 核对视图独立重算账单抵扣／核销／余额、收款核销／退款／未核销额、采购验收／付款和押金余额，与业务缓存比较，差异及负余额不会被静默归零。

| 来源             | 原始台账                             |
| ---------------- | ------------------------------------ |
| 收款、退款、作废 | hylReceipts、hylReceiptEntries       |
| 押金、合同补缴   | hylLeaseEntries                      |
| 商户应返及返款   | hylSettlements、hylPayments          |
| 供应商应付及付款 | hylPurchaseOrders、hylPurchaseLedger |
| 分账收付         | hylSplitOrders、hylSplitTransfers    |

统一收银订单、日结快照、采购计提不重复计入现金。

## 权限与接口

入口需要 `page:hyl-financial-reports/access`。API 需要 `hyl.finance/read` 的 contracts 与 assets 范围，以及合同 read、billingRead、receiptRead、depositRead、cashierReconcileRead、splitRead，商户 read、结算 read、资产 read、采购 financeRead。统计取原权限交集，缺少必要业务操作返回403；隐藏或不存在的来源返回404，不泄露隐藏数量和名称。

采购还检查供应商所属资产，以及关联工单的资产、商户和合同权限。结算来源的分账收付仍检查原结算权限。项目选项受资产权限限制。既有角色没有被自动追加授权；系统管理员可用，业务角色由现有权限管理配置页面和业务动作范围。演示没有新增账号或扩大权限。

单项目筛选仅包含恰好属于该项目的合同。多项目及未绑定资产合同仅在全部授权项目范围展示，不任意分摊一笔金额。

- `GET /financialReports`：汇总、核对及分页明细；参数和响应见运行中的 API 文档。
- `GET /financialReports/:kind/:id`：当前范围内的财务来源明细，抽屉保留项目、期间及视图。

服务在事务外解析权限，事务内只使用传入连接读取同一快照。只读汇总不需要新表、迁移或定时同步。
