# 计费、账单与收款核销

入口为“计费与账单”，分为账单、收款两个列表；合同详情也有计费汇总及办理入口。

## 业务规则

- 租金按合同选择“经营结算扣租”或“独立账单收租”，两者互斥。旧合同默认继续经营扣租，历史结算快照不改。已有有效账单、经营结算或未处理收款时不能切换渠道。
- 租金、固定物业费和面积物业费按合同有效日期与月／半月周期的交集计算：月费 × 实际包含天数 ÷ 当月实际天数。面积物业费先使用签约资产快照中的可租面积乘月单价，再按天折算，最后四舍五入到分。
- 水、电、燃气使用人工登记的表号、读数、倍率和单价。用量为本期减上期再乘倍率，不重复按天折算。首读、零用量、换表、停表需有凭证。相邻读数必须连续，期间不能重叠。
- 费率按生效周期版本保存。后续版本只能从尚未出账的周期边界生效，旧账单保持原价。费用启停按版本区间判定，不能追溯改变历史渠道。续租可在新合同配置页复制旧规则供核对，新的启用读数和凭证仍需填写。
- 启用账单收费的物业、水电燃气期间，费用台账不能再登记相同费用用于经营扣费；已有费用也会阻止重复配置或出账。一次性费用按明确参考号去重，独立押金扣款不得重复使用其来源。

## 办理顺序

1. 在合同内配置收费规则和预期抄表表号；生成时选择月份、合同周期、费用类型及到期日，录入抄表和一次性费用。
2. 先预览计算明细，再保存草稿；草稿可编辑，修改后需重新预览。发布后产生应收，明细锁定。作废保留原始记录，已有有效抵扣／核销的账单须先冲销相应流水。
3. 押金抵扣只使用该合同可用押金，并同时减少账单剩余应收；押金流水冲销同时恢复账单欠款。
4. 登记收款仅增加“未核销金额”，不会自动清掉欠款。再选择同合同账单核销，支持部分核销及一笔收款核销多张账单。不支持跨合同或跨商户混合核销。
5. 多收的未核销余额可登记线下退款；已核销的金额须先冲销核销才能退款。错误核销、退款可以凭原因和凭证冲销，原始流水保留。
6. 退租预览检查超出实际结束日的账单，不能静默修改已出账金额。归档检查草稿、欠款、未核销收款、押金、经营结算，以及所有已启用费用／预期表号的完整期间覆盖。临时抄表缺口确认不能豁免末期费用。
7. 有凭证的零额账单发布后直接显示已结清，不产生应收和现金流，但会作为零用量期间的覆盖证据。归档后账务只读；更正须先显式重新打开合同，资产占用和实际结束日期不因此恢复。

剩余应收 = 已发布账单金额 − 有效押金抵扣 − 有效收款核销。

未核销金额 = 收款金额 − 有效核销 − 有效余额退款。

所有收付款均为线下凭证台账，不调用支付、银行、开票或设备接口，也不自动定时扣款。

## 手工费用来源与收款流水

- 新建账单的其他费用使用选填的“来源单号”和必填的“收费依据”。来源单号为空时，服务端按操作请求号与明细序号生成 `FY-…` 费用编号，并同时保存到账单输入快照和费用明细；重试沿用原请求号，编辑既有明细保留已保存编号。手工填写的来源单号继续执行跨账单、经营费用及押金流水的既有冲突检查。
- 生成费用编号用于识别费用和防止同一操作重复出账，不代表已收款，也无法识别不同请求中重复录入的相同现实费用。
- 收款登记和统一收银使用“支付流水号”：银行转账必填；现金和其他方式选填，留空由系统生成 `SK-…` 内部编号，保留原有收款参考号的防重和核销逻辑。退款的原有凭证要求保持有效。
